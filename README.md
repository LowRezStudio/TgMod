# Tempest Mod

![Discord](https://img.shields.io/discord/1371416079158476820?style=social&logo=discord&link=https%3A%2F%2Fdiscord.gg%2FyZDuxAk4d9)

This Mod gives access to multiplayer and the developer Console.

Full list:

F1: Allows you to open the shooting range only when in the process of logging in
F2: Opens the Dev console

Unlocks the maximum FPS 175 -> 300
Allows you to host and play multiplayer servers found in the server list.
