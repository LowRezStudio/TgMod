# TempestMp

![Discord](https://img.shields.io/discord/1371416079158476820?style=social&logo=discord&link=https%3A%2F%2Fdiscord.gg%2FyZDuxAk4d9)

This mod is necessary for multiplayer in Tempest and contains the login and player spawn logic, bypassing the need of Hi-Rez's login servers.

It can also serve as a template for other scripting mods.
